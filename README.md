## O que tem no site

- Cronograma macro (visão da semana inteira)

- Cards expansíveis com informações sobre cada empresa, endereço e link para o Google Maps
- Checklist de bagagem interativo
- Previsão do tempo
- Divisão de quartos dos dois hotéis

## Como publicar

O site é um único arquivo `index.html` — não precisa de build nem instalação.

1. Faça upload do `index.html` neste repositório
2. Vá em **Settings → Pages**
3. Em **Branch**, selecione `main` e salve
4. Em 1–2 minutos o site estará no ar

## Como atualizar

Abra o `index.html` aqui no GitHub, clique no ícone de lápis (✏️), edite e faça commit.
O site atualiza sozinho em poucos minutos.

Itens marcados como *"a definir"* no site são os que ainda faltam confirmar.
